PIZZA SALES ANALYSIS
 
 
 Project Summary

This project demonstrates a real-world **end-to-end data analytics workflow** using SQL for data extraction and transformation, followed by data modeling and visualization in Power BI.  
It showcases how raw data is cleaned, transformed, explored, and visualized to generate actionable insights — replicating typical tasks performed by professional data analysts.

✔️ Data preparation & transformation (SQL)  
✔️ Interactive dashboard build (Power BI)  
✔️ Clear narrative of business insights  
✔️ Fully documented and reproducible workflow

 Project Description

In this repository, you will find a complete analytics project designed to illustrate analytical thinking, data manipulation skills, and storytelling with data.  
The project follows a structured workflow:

- Extract data and import into a SQL database  
- Clean and transform datasets with SQL  
- Build queries to answer business questions  
- Import prepared data into Power BI  
- Generate an interactive dashboard to visualize findings


Objectives

- Provide a **clear, documented analytics project** for hiring managers.  
- Highlight practical use of **SQL & Power BI** to solve business problems.  
- Deliver **actionable insights** through visualization and interpretation.  
- Demonstrate ability to translate data into **business decisions**.
